## 🌱 [GreenLedger AI](https://github.com/gurleen26)

**AI-powered ESG data extraction and BRSR analytics platform**

GreenLedger AI processes unstructured corporate documents such as **PDFs, scanned documents and Excel data** to extract ESG information and compute **46+ BRSR Core KPIs**.

**Tech:** Python • FastAPI • Express.js • AWS S3 • AWS Bedrock • FAISS • RAG • Redis • BullMQ • PyMuPDF

**Key Concepts:**
`RAG` `LLMs` `Embeddings` `Document AI` `Vector Search` `ESG Analytics`

## 🧍 [PostureMed](https://github.com/gurleen26)

**AI-based patient posture monitoring system for physiotherapy**

A computer-vision system that analyzes body posture using **33 body landmarks**, identifies posture deviations and provides real-time feedback.

**Tech:** Python • OpenCV • MediaPipe BlazePose • FastAPI • WebSockets • SQLite • Chart.js

**Key Concepts:**
`Computer Vision` `Pose Estimation` `Real-Time Processing` `WebSockets` `REST APIs`
